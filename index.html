Project Title: The Server Commander (SysAdmin & Infrastructure Provisioning)

Overview

This server was manually provisioned and configured as part of the DecodeLabs Cloud Computing program. Instead of using serverless managed hosting, this project demonstrates full system control, OS management, network firewall configuration, and web server installation.

Execution Steps Completed

  • ✔ Provisioned an Ubuntu 24.04 LTS VM on Microsoft Azure (uaenorth region)
  • ✔ Configured Network Security Group (NSG) to allow inbound SSH (Port 22) & HTTP (Port 80)
  • ✔ Authenticated securely via SSH using a private key (.pem)
  • ✔ Updated Linux system repositories via APT package manager
  • ✔ Installed and initialized Nginx web server on port 80
  • ✔ Customized system web root directory (/var/www/html/index.html)
